# Crabb-At-cLab — เช็คชื่อรับ-ส่งพนักงาน

เว็บแอพสำหรับมือถือ ใช้เช็คชื่อตอนรับ-ส่งพนักงาน

- พนักงานลงชื่อเอง เลือกจุดรับ-ส่งจุดเดียว แก้ไขภายหลังได้ (ปุ่ม ✏️)
- คนเช็คชื่อติ๊กยืนยันว่ารับ/ส่งแล้ว สลับ "รอบรับ / รอบส่ง" ได้
- ปุ่มรีเซ็ตเครื่องหมายเพื่อเริ่มรอบใหม่
- ช่องหมายเหตุ (มาไม่ได้, เปลี่ยนจุด, อื่นๆ)
- ข้อมูลใช้ร่วมกันทุกเครื่อง อัปเดตอัตโนมัติทุก 4 วินาที

## วิธีรัน

```
npm start        # หรือ node server.js  (ต้องมี Node 16+, ไม่ต้อง npm install)
```

เปิด `http://<ip เครื่อง>:3000` จากมือถือ (ตั้ง `PORT` ได้ ข้อมูลเก็บใน `data.json`)
